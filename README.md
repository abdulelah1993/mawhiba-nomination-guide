# الدليل الإرشادي لمقياس موهبة التجريبي

نسخة متعددة الصفحات بناء على الكود الذي أرسله صاحب المشروع. سبع صفحات: الرئيسية، قبل الاختبار، تسجيل الدخول، تهيئة الجهاز، التحقق من الطالب، أداء الاختبار، والمساعدة والدعم.

تتضمن 21 خطوة وصورًا أصلية من العرض الإرشادي، مع البحث، وتكبير الصور، وتحديد الخطوات المنجزة (محليًا في المتصفح)، وشعارات موهبة ووزارة التعليم وهيئة تقويم التعليم والتدريب.

## التشغيل

```bash
node build.js
python -m http.server 8000 -d dist
```

## النشر

الخدمة المستقلة على Render باسم `mawhiba-olympiad-guide` تعتمد فرع `olympiad-guide-standalone`. Render يشغّل `node build.js` ثم ينشر المجلد `dist`. هذا لا يغير فرع `main` الخاص بموقع دليل الترشيح.

تنبيه: هذه صفحة إرشادية وليست منصة اختبار. تُراجع تعليمات ومواعيد الاختبار مع الجهة المنظمة قبل المشاركة العامة.
