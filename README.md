# الدليل الإرشادي لمقياس موهبة التجريبي

نسخة الموقع المستقل بعد عكس عرض PowerPoint المرفق «الدليل الارشادي لمقياس موهبة التجريبي.pptx».

- صفحة واحدة تضم ٢١ خطوة من الدخول حتى التسليم، موزعة على ١٦ بطاقة مصوّرة.
- نصوص الشرائح والصور المضمنة فيها هي المصدر، وليست معلومات أضيفت من خارج العرض.
- يتضمن المتطلبات التقنية، والأذونات، والمخالفات، وحلول المشكلات، والدعم الفني عبر البريد gig@mawhiba.org.sa.
- واجهة عربية RTL متجاوبة مع الجوال، وصور ظاهرة ويمكن تكبيرها، وبحث وطباعة.
- صورة الشعار مأخوذة من خلفية العرض الإرشادي.
- ملف index.html مستقل بكل الصور ولا يحتاج لخادم تطبيقات أو قاعدة بيانات.

## النشر على Render

يعتمد النشر على الخدمة المستقلة التي أنشأتها سابقًا من هذا الفرع، والتي لا تغيّر موقع دليل الترشيح:
- المستودع: https://github.com/abdulelah1993/mawhiba-nomination-guide
- الفرع: `olympiad-guide-standalone`
- Static Publish: `./public`
- Build command: `mkdir -p public && cp index.html public/index.html`

## ملاحظة المصدر

الشريحة الخاصة باختيار الاختبار تُظهر النص «اختر «» بحسب التخصص المطلوب»، دون كتابة اسم الخيار. احتُفظ بالنص كما ورد، مع تنويه على الصفحة، دون افتراض تسمية غير موثّقة.
