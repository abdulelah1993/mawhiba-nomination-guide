# دليل ترشيح الطلبة | موقع جاهز للنشر على Render

صفحة عربية تفاعلية بتصميم مستوحى من ملف «إحصائيات التسجيل»، تعرض **10 خطوات** موزعة على **3 مراحل** من الدليل المرفق. تعمل دون خادم أو قاعدة بيانات، وتتضمن الصور الأصلية مع إخفاء البريد الإلكتروني الظاهر في لقطات الشاشة قبل المشاركة العامة.

## معاينة محلية

افتح `index.html` مباشرة في المتصفح، أو شغل خادمًا محليًا داخل مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر على Render عبر GitHub

1. فك ضغط الملف ZIP وارفع **محتويات المجلد** إلى مستودع GitHub خاص بك (اجعل `render.yaml` و `index.html` في جذر المستودع).
2. في لوحة [Render](https://dashboard.render.com/) اختر **New → Blueprint**، ثم صِل مستودع GitHub وحدد `render.yaml`.
3. راجع اسم الخدمة ثم وافق على إنشاء الموقع. سينشر Render المجلد `public` الذي ينتجه أمر البناء تلقائيًا.
4. انسخ رابط الموقع `onrender.com` وشاركه. عند تعديل الملفات ودفعها إلى GitHub، يحدّث Render الموقع وفق إعدادات النشر لديك.

### بديل: إنشاء Static Site يدويًا

* **New → Static Site** ثم اختيار المستودع.
* **Build Command:** `mkdir -p public && cp -R index.html styles.css app.js assets public/`
* **Publish Directory:** `public`

لا يلزم اشتراك مدفوع لإعداد هذه الصفحة؛ اختيار الخطة والقيود يعتمد على حسابك في Render.

## المزايا

- واجهة عربية RTL متجاوبة للجوال والكمبيوتر.
- صور الدليل الأصلية مع معاينة وتكبير وانتقال بين الصور.
- 10 خطوات، 3 مراحل، فهرس بحث وتصفية.
- تذكر الخطوات التي اطلعت عليها **محليًا في متصفحك**، دون إرسال بيانات إلى الخادم.
- مشاركة رابط مباشر لأي خطوة مثل `#step-5`.
- وضع ليلي وطباعة الدليل كاملًا.
- روابط رسمية لتنفيذ الترشيح في https://admin.mawhiba.sa/ .

## تعديل المحتوى

الخطوات والنصوص في بداية `app.js` ضمن المتغير `steps`. صور كل خطوة في `assets/step-01.webp` إلى `step-10.webp`، والشعارات في `assets`.

**ملاحظة:** الموقع للشرح فقط ولا يتصل بحسابات موهبة أو بيانات الطلبة. صور المنصة توضيحية وتعكس ما ورد في ملف الدليل، وقد تختلف واجهة المنصة الحية لاحقًا. لا تعكس الصفحة أي أرقام إحصائية حية.
